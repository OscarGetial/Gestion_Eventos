# Eventia — Gestión de eventos

Proyecto de maquetación web responsiva para una página de gestión de eventos.

## Entregables

1. **Maquetación Web Responsiva:** Home Page en HTML5 + CSS3 con enfoque **Mobile-First** y adaptación a tablet/escritorio.
2. **Trazabilidad y Gestión en Jira:** Historias de Usuario, Tareas y Subtareas documentadas y relacionadas con el maquetado.
3. **Control de Versiones en GitHub:** estructura de carpetas y código fuente preparada para el repositorio del equipo.
4. **Seguimiento Ágil (Scrum Daily):** tabla de reuniones diarias con avance, impedimentos, soluciones e indicadores.

## Enlaces oficiales del equipo

- **GitHub:** https://github.com/OscarGetial/Gestion_Eventos
- **Jira / Scrum:** https://uceva-team-gbg1xixs.atlassian.net/jira/software/projects/SCRUM/boards/1/timeline

## Estructura

- `index.html` — Home Page.
- `css/styles.css` — estilos responsivos.
- `js/main.js` — interacción básica del menú.
- `docs/jira-trazabilidad.md` — historias, tareas, subtareas y criterios.
- `docs/github-control-versiones.md` — control de versiones y enlace real del repositorio.
- `docs/scrum-daily.md` — seguimiento de Daily Scrum.
- `docs/evidencias.html` — índice de evidencias.
- `jira/jira-import.csv` — datos base para registrar el trabajo en Jira.
